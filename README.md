## محدودیت‌های فعلی

- **مدل آفلاین واقعی** (مثل اجرای مدل روی خود گوشی): به خاطر حجم بالا و پیچیدگی، فعلاً پیاده‌سازی نشده. حالت آفلاین فعلی پاسخ‌های ساده محلی می‌دهد.
- **جست‌وجوی اینترنت زنده**: نیاز به API جداگانه دارد. فعلاً مدل از دانش خودش استفاده می‌کند.

## چطور روی گوشی نصب کنم؟

### ۱. نصب Android Studio
- برو به: https://developer.android.com/studio
- دانلود و نصب کن
- باز کن و Next بزن تا تنظیمات اولیه تمام شود

### ۲. باز کردن پروژه
- در Android Studio روی **Open** کلیک کن
- پوشه `MyAI` را انتخاب کن
- صبر کن تا Gradle همگام شود

### ۳. ساخت APK
- منو: **Build → Build Bundle(s) / APK(s) → Build APK(s)**
- بعد از اتمام روی **locate** کلیک کن
- فایل `app-debug.apk` را بردار

### ۴. نصب روی گوشی
- فایل را به گوشی بفرست و نصب کن
- اجازه میکروفون را در اولین استفاده بده

## بعد از نصب

1. برو به تنظیمات → تب «مدل هوش مصنوعی»
2. کلید رایگان از console.groq.com بگیر و وارد کن
3. ذخیره کن
4. شروع به گفتگو کن (نوشتن / صحبت / فایل)
